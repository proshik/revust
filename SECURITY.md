# Security reporting

revust launches locally configured provider CLIs and saves review inputs,
prompts and provider output. Treat archives as potentially sensitive and choose
trusted executables and configuration. Call/time limits are not monetary caps.
Provider permissions and credentials remain subject to each CLI's configuration;
see [qualified executor boundaries](docs/executor-protocols.md).

No public release or security support window has been established yet. Report
sensitive vulnerabilities through GitHub private vulnerability reporting once
enabled by the owner. Until that channel exists, do not disclose secrets or
exploitable private details in public issues; contact the repository owner via
an already established private channel. Never include credentials or private
archives in a report. Ordinary bugs can use a sanitized reproduction.
