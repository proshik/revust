## Explanations in source

Compare comments and API documentation to the code they describe. Flag incorrect guarantees or obsolete explanations that could cause a caller or maintainer to use the code incorrectly.

Inspect claims about consistency, delivery, retry safety, resource ownership and compatibility against the implementation and dependency contracts. Report a misleading or missing explanation only with the concrete misuse it enables; do not require commentary that merely repeats clear code.
