## Existing project solutions

Inspect similar paths in this repository for contracts and implementation precedents. Explain where the issue differs before recommending reuse. Existing code is evidence of convention, not proof of correctness.

Look for existing transaction, messaging, idempotency, migration and compatibility mechanisms before proposing another. Compare their guarantees and caller context, including retry/recovery and ordering requirements; a similar implementation or library choice is neither a mandate nor proof that this case is safe.
