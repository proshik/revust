# Guild adapter contract

The launcher requires terminal protocol version 1 and archive_viewer, carrying
absolute directory/program metadata. Reopening invokes `PROGRAM view --archive
DIRECTORY` without another review. No fallback field or protocol migration exists.
Source-ready companion e7fde36e includes neutral metadata and task recovery;
installed Guild qualification is separate. This repository ships no patch to
apply to Guild. See [host boundaries](../../docs/hosts.md).
